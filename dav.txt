1. Machine Learning Models
In  train_diabetes.py, 3 classification models are trained, evaluated, and compared on the same stratified train/test split:

Logistic Regression (LogisticRegression(max_iter=1000, solver="lbfgs"))
Decision Tree Classifier (DecisionTreeClassifier(max_depth=6, min_samples_leaf=8))
Random Forest Classifier (RandomForestClassifier(n_estimators=200, max_depth=8, min_samples_leaf=4))
Model Selection Strategy: The pipeline compares all three models on held-out test data using the roc_auc metric (

train_diabetes.py:L87
). Random Forest achieved the highest score and is saved to model.joblib to serve live predictions in the Flask web app. 
(Note: As noted in  README.md
, placeholders exist in the repository layout for future models like XGBoost and CatBoost, but currently these 3 are implemented).
